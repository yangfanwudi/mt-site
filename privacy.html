我叫MT：崛起 · 攻略站 是个人作品展示站点，托管在 GitHub Pages 上。本页说明本站如何处理访问者可能产生的信息，并尽量把选择权留给你。

1. 本站主动收集的信息

本站目前没有接入访问统计、广告脚本或第三方分析服务，也没有设置自有 cookie。除下文说明的情形外，本站不会主动收集、存储或分享你的个人信息。

页面会在你的浏览器本地保存一项语言偏好（localStorage），用来记住你选择的中文或英文界面。这项数据只存在你的设备上，不会发送给本站或任何第三方；清除浏览器数据即可删除。

2. 托管平台日志

本站由 GitHub Pages 托管。GitHub 可能按照其隐私声明记录访问日志（例如 IP 地址、浏览器类型、访问时间），用于安全与运维。这部分数据不在本站的控制范围内，详见 GitHub 隐私声明。

3. 反馈邮件

如果你通过反馈页或邮箱联系我们，我们会收到你的邮箱地址、邮件正文和附件。这些信息仅用于回复问题、处理反馈和改进作品，不会出售或主动提供给第三方。你可以随时来信要求删除此前的邮件往来。

4. 交流区与评论

本站交流区使用 giscus。发表评论需要登录 GitHub 账号，评论内容存储在 GitHub Discussions 中，并受 GitHub 隐私政策约束；本站不另行存储评论数据。如果你不希望登录 GitHub，可以改用反馈邮箱联系我们。

5. 外部链接

本站包含指向其他网站的链接：GitHub（giscus 评论）、游戏官方或社区页面。这些网站有自己的隐私政策，本站不对其内容或数据处理方式负责。

6. 广告与第三方 Cookie

本站目前不展示广告。未来若接入 Google AdSense 等第三方广告服务，Google 及其合作方可能使用 cookie 或类似技术，根据你此前访问本站和其他网站的情况展示广告。届时你可以通过 Google 广告设置 或 aboutads.info 管理个性化广告。广告上线前我们会更新本页并注明日期。

7. 未成年人

本站不是面向儿童的产品，也不会主动收集未成年人的个人信息。如果你是未成年人，请在监护人指导下使用本站；如需联系我们，请让监护人知情。

8. 政策变更

如果本站的数据处理方式发生变化，我们会更新本页并修改文末日期。涉及广告、统计或账号体系的重大变化，会在站点首页同步说明。

9. 联系方式
